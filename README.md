# Análisis exploratorio y modelado predictivo de riesgo crediticio — Lending Club

## Introducción

El análisis de riesgo crediticio es un aspecto fundamental para las plataformas de préstamos en línea, ya que permite evaluar la probabilidad de que un prestatario incumpla con sus obligaciones financieras. En este contexto, la plataforma **Lending Club** ofrece un amplio conjunto de datos históricos sobre préstamos otorgados, incluyendo información financiera, demográfica y crediticia de los solicitantes.

Este proyecto tiene como objetivo desarrollar un modelo de clasificación supervisada capaz de predecir si un préstamo emitido por Lending Club resultará en **default (1)** o será **pagado completamente (0)**.

Como primera etapa, se realizó un **Análisis Exploratorio de Datos (EDA)** para comprender la estructura del conjunto de datos, identificar valores faltantes, detectar inconsistencias y analizar la distribución de las variables más relevantes.

Posteriormente, se entrenaron y compararon modelos de aprendizaje automático implementados tanto en **Scikit-learn** como en **PySpark**, evaluando su desempeño mediante diferentes métricas de clasificación. Finalmente, se utilizó **LIME (Local Interpretable Model-Agnostic Explanations)** para interpretar las predicciones y comprender la contribución de cada variable en las decisiones del modelo.

---

# Objetivo

Construir un modelo de clasificación supervisada para predecir si un préstamo emitido por la plataforma **Lending Club** resultará en **default (1)** o será **pagado completamente (0)**.

Como objetivos específicos se busca:

- Realizar un análisis exploratorio del conjunto de datos.
- Preparar y limpiar la información para el entrenamiento de modelos.
- Comparar el desempeño de modelos implementados con **Scikit-learn** y **PySpark**.
- Evaluar los modelos mediante métricas de clasificación.
- Interpretar las predicciones utilizando **LIME**.

---

# Dataset

El proyecto utiliza información histórica de préstamos de **Lending Club**, incluyendo variables financieras, demográficas y crediticias de los solicitantes.
